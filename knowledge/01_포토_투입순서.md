# 01. 포토(노광) 병목과 투입 순서

## 1. 현업 상황
- 포토는 층마다 그림을 그리는 공정이라, 한 로트가 포토를 수십 번 다시 찾아온다(재진입). 한 로트가 최대 40번 지난다는 사례가 있다. — [WSC 2020 STMicro](https://informs-sim.org/wsc20papers/184.pdf)
- 노광기는 한 장씩, 칩 몇 개씩 찍어서 느리고(시간당 웨이퍼 약 100~220장), 한 대에 수천억 원이라 많이 살 수 없다. 그래서 팹의 병목이 되기 쉽다.
- 삼성은 일부러 포토를 병목으로 설계했다. 정상일 때도 팹 대기 물량의 30~40%가 포토 앞에 쌓였다. — [삼성 SLIM 논문](https://ieor.berkeley.edu/wp-content/uploads/2019/10/SLIM.pdf)
- SK하이닉스 뉴스룸: 포토는 전공정 중 처리 시간이 가장 길고 재작업이 가능한 유일한 공정이다. — [SK하이닉스 뉴스룸](https://news.skhynix.co.kr/post/the-bottom-part-of-the-photo-process)
- 하이닉스 1c DRAM은 EUV 층이 5개 이상이다. 비싼 EUV를 거치는 횟수가 늘고 있다. — [ZDNet](https://v.daum.net/v/20250811165522217)

## 2. 현업을 괴롭히는 제약
| 제약 | 내용 | 출처 |
|---|---|---|
| 마스크(레티클) 1장 | 같은 층 마스크가 한 장이면 노광기 두 대에서 동시에 못 돌린다. 다른 노광기가 놀아도 기다린다 | [국내 논문 2004](https://koreascience.kr/article/JAKO200410103467342.pdf) |
| 교체 시간(setup) | 마스크·레시피를 바꿀 때 시간이 든다. 실데이터에서 1초~5분 넘게, 앞뒤 순서에 따라 다르다 | [IEEE TSM 2023](https://pure.tue.nl/ws/portalfiles/portal/312407041/Scheduling_a_Real-World_Photolithography_Area_With_Constraint_Programming.pdf) |
| 마스크 상자(pod) | 상자가 한 장비에 있으면 그 안 마스크는 다른 장비가 못 쓴다. 이송 시간도 있다 | 같은 출처 |
| 마스크 창고 | 마스크 4,000장 이상, 하루 1,600장 사용. 자주 쓰는 마스크를 빠른 칸에 두니 빠른 칸 비율 8%→20% | [WSC 2020](https://informs-sim.org/wsc20papers/184.pdf) |
| 장비 고정(dedication) | 오버레이 때문에 앞 층을 찍은 노광기에서 다음 층도 찍어야 하는 경우. 특정 장비 앞에만 줄이 길어진다 | [삼성 SLIM](https://ieor.berkeley.edu/wp-content/uploads/2019/10/SLIM.pdf), [국내 논문 2017](https://koreascience.kr/article/JAKO201710960151306.page?lang=en) |
| 장비 자격 | 로트마다 돌릴 수 있는 장비가 정해져 있다 | [WSC 2021](https://www.informs-sim.org/wsc21papers/156.pdf) |

## 3. 데이터 모양 (예상)
- 로트 표: `lot_id`, 제품, 현재 층(step), 도착 시각, 납기, 우선순위(hot/일반)
- 장비 표: `eqp_id`, 상태(가동/PM/고장), 현재 장착 마스크
- 자격 표: 어떤 제품·층을 어느 장비가 돌릴 수 있나, 앞 층 장비 고정 여부
- 마스크 표: `reticle_id`, 제품·층, 현재 위치(창고/장비), 사용 횟수
- 교체 시간 표: 앞 마스크 → 뒤 마스크일 때 걸리는 시간

### 공개 데이터셋 참고: SMT2020
- 디스패칭 연구용 공개 가상 팹 데이터. 장비 1,000대 이상. — [SMT2020 논문 정보](https://cris.iucc.ac.il/en/publications/smt2020-a-semiconductor-manufacturing-testbed-2/), [PySCFabSim(데이터 포함)](https://github.com/prosysscience/PySCFabSim-release)
- 파일과 열: `WIP.txt`(LOT, PART, PRIOR, PIECES, START, CURSTEP, DUE, HOTLOT), `order.txt`(투입 계획), `route_N.txt`(STEP, STNFAM, PTIME, BATCHMN/MX, SETUP, CQT=Q-time, REWORK), `tool.txt`(STNFAM, STN, RULE, 순위 기준, SETUPGRP), `setup.txt`(CURSETUP→NEWSETUP 교체 분), `downcal.txt`(MTTF, MTTR).
- 기본 장비 규칙: `rule_HotLotFIRST` + 순위 `rank_HP; rank_RSETUP; rank_FIFO` = 급한 로트 먼저 → 우선순위 → 교체 줄이기 → 먼저 온 순. "Priority + 같은 마스크"와 같은 생각이다.

## 4. 후보 로직과 언제 쓰나
| 로직 | 쉬운 설명 | 이럴 때 맞다 | 약점 |
|---|---|---|---|
| **FIFO (먼저 온 순)** | 장비가 비면 가장 오래 기다린 로트 | **기준선.** 공정하고 단순 | 납기·교체 시간 무시 |
| **EDD / CR (납기 급한 순)** | 납기가 가장 가깝거나 남은 시간 대비 남은 일이 많은 로트 | 담당자가 "납기 지연"이 제일 아프다고 할 때 | 교체가 잦아져 처리량 손해 |
| **같은 마스크 묶기 (setup 최소화)** | 지금 장착된 마스크를 쓰는 로트를 먼저 | "교체 시간·마스크 이동"이 아플 때 | 다른 마스크 로트가 오래 굶음 → 최대 대기 상한을 둔다 |
| **점수식 규칙** | 우선순위·대기 시간·납기·같은 마스크 여부에 가중치를 줘서 점수가 높은 로트 | 아픈 곳이 여러 개일 때. 현업에서 가장 흔함 | 가중치를 정하는 근거가 필요 |
| **짧은 주기 재최적화** | 몇 분마다 앞으로 올 로트를 예측해 최적 순서를 다시 계산(수리 최적화·제약 프로그래밍) | 데이터가 충분하고 시간이 있을 때 | 구현·검증 시간이 큼 |
| **강화학습** | 시뮬레이션 속에서 반복 연습해 규칙을 스스로 배움 | 결선 시간 안에는 비추천. 한계로만 언급 | 시뮬레이터 필요, 설명 어려움 |

- 현업 설문(2007년, 14개 회사 16명): 디스패칭 규칙이 주 수단이고, 대기 로트의 75~85%가 우선순위가 같아 "동점일 때 누구 먼저"가 중요하다. 사이클 타임 중심 팹은 **Priority FIFO**(급한 것 먼저 + 먼저 온 순), 납기 중심 팹은 **Priority CR**(급한 것 먼저 + 빠듯한 순)을 쓴다. — [FabTime](https://www.inficon.com/media/11333/download/FabTimeNewsletter8.07.pdf) (벤더)
- CR(여유 비율) = 납기까지 남은 시간 ÷ 앞으로 남은 작업 시간. 1보다 작으면 이미 늦는 중이다. 작을수록 먼저 넣는다. 회사마다 계산법이 조금씩 다르고, 납기가 이미 지난 로트를 더 끌어올리도록 고쳐 쓰기도 한다. 병목 장비가 굶지 않게 앞뒤 공정 상황까지 보는 규칙도 있다. — 같은 출처 6~7쪽

## 5. 실제 성과 숫자 (참고용, 회사·벤더 발표 포함)
| 사례 | 방법 | 성과 |
|---|---|---|
| 삼성 SLIM (1996~1999) | 단계별 목표 시간·목표 대기량, 병목 앞 버퍼 | DRAM 완성 기간 80일 이상 → 30일 미만, 추가 매출 약 10억 달러 |
| Applied SmartSched | 몇 분마다 재계산 + 마스크 미리 이송 지시 | 처리량 2.1%↑, 급한 로트 시간 약 20%↓ (벤더) — [기사](https://sst.semiconductor-digest.com/?p=31214) |
| Seagate (Flexciton) | 5분마다 최적화, MES와 연결해 1년 이상 운영 | 처리량 9.4%↑, 대기 4.3%↓, 마스크 이동 5.3%↓ — [WSC 2022](https://informs-sim.org/wsc22papers/353.pdf) |
| 2단계 스케줄링 논문 | 수리 최적화 | 마스크 배송 40.5%↓ |
| KAIST+삼성디스플레이 | 강화학습 + 마스크 사용 중인 로트 제외 | 기존 규칙보다 납기 지연 28~32% 적음 — [WSC 2021](https://www.informs-sim.org/wsc21papers/156.pdf) |
| Infineon | 디지털 트윈 + 강화학습 | 납기 지연 18~37%↓ — [WSC 2023](https://www.informs-sim.org/wsc23papers/doc102.pdf) |
| SK하이닉스 | 2030 자율형 팹(오퍼레이션 AI, 디지털 트윈). 포토 투입 알고리즘은 미공개 | — [인더뉴스 2026](https://www.inthenews.co.kr/news/article.html?no=84388) |
