# 04. 장비·공정 이상 감지와 원인 설명

상태: 초안.

## 1. 현업 상황과 근거
- SPC(3-4): 관리한계 UCL/LCL은 평소 범위, 규격 USL/LSL은 합격 범위. 연속 7점 한쪽 같은 규칙.
- FDC(3-5): 센서 trace를 레시피 단계별 요약값으로 바꿔 기준과 비교. 센서 결측·이상값·불균형이 흔하다. — [국내 논문 2024](https://koreascience.kr/article/JAKO202425637078801.pdf), [UCI SECOM](https://archive.ics.uci.edu/dataset/179/secom)
- 하이닉스 사례: 장비 간 매칭으로 이상 탐지, 변수 기여도 설명(GRACE), 물류 장애 예측(AMOS). — [뉴스룸 2026](https://news.skhynix.co.kr/spie-al-2026-with-gauss-labs/), [뉴스핌](https://www.newspim.com/news/view/20260625001090)

## 2. 데이터와 정할 것
- **데이터**: 센서 시계열 또는 요약값, 레시피 단계, 알람 이력, 불량 결과(조금)
- **정할 것**: 이상 판정 규칙과 등급, "왜 이상인지" 변수 기여도
- **목표**: 놓침 줄이기, 헛경보 줄이기, 엔지니어가 납득할 설명

## 3. 후보 로직 (기준선부터)
1. 기준선: 고정 관리한계(평균 ±3σ) 넘으면 경보
2. 추세 규칙: 같은 방향 연속 n회, 한계의 50·70% 넘으면 주의·경고
3. 레시피·챔버별 기준선 따로 잡기
4. 다변량·모델 기반 이상 점수 + 변수 기여도
