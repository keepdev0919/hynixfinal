# 05. 웨이퍼 맵·불량 이미지 분류

상태: 초안.

## 1. 현업 상황과 근거
- WM-811K: 웨이퍼 맵 811,457장 중 172,950장 라벨, 약 85%가 None(패턴 없음). 패턴: Center, Donut, Edge-Loc, Edge-Ring, Loc, Near-full, Random, Scratch. — [arXiv 2411.11029](https://arxiv.org/html/2411.11029v1)
- 하이닉스 사례: 이미지 불량 검사 자동화(IVIA)로 반복 수작업 90% 이상 감소, 신규 불량 탐지·적은 데이터 학습을 과제로 꼽음. — [뉴스룸 2020](https://news.skhynix.co.kr/?p=17706)

## 2. 데이터와 정할 것
- **데이터**: 다이 격자(정상/불량) 또는 불량 이미지, 일부 라벨
- **정할 것**: 패턴 이름, 처음 보는 패턴 걸러 내기
- **목표**: 사람이 보던 시간 줄이기, 신규 패턴 알림

## 3. 후보 로직 (기준선부터)
1. 기준선: 규칙(가장자리 링 불량 비율, 중심 불량 비율 등)으로 분류
2. 특징값 + 간단한 분류 모델
3. 이미지 모델(CNN 등), 시간 안에 검증 가능할 때만
4. 신규 패턴: 기존 패턴과의 거리가 멀면 '모름'으로 표시
