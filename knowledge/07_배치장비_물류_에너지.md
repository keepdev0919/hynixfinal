# 07. 배치 장비 대기, 물류, 유틸리티

상태: 초안.

## 1. 현업 상황과 근거
- 배치 장비(가열로 등): 같은 레시피 로트 여러 개를 한 번에 처리. 덜 채워 돌리기 vs 모으느라 기다리기. 더미·모니터 웨이퍼, 위치 효과. — [SK 산화 칼럼](https://news.skhynix.co.kr/jeonginseong-column-oxidation/)
- Q-time(3-7): 앞 공정 후 정해진 시간 안에 다음 공정. 넘기면 처음부터 다시. — [INFICON/FabTime](https://www.inficon.com/ko/소식/managing-time-constraints-between-process-steps-in-wafer-fabs) (벤더)
- 물류: 이천 팹 OHT 약 1,000대·레일 약 30km, 정체 우회 경로 모델. — [전자신문](https://m.etnews.com/20231124000184)
- 에너지: 냉동기 운전 변수 2,565개 분석 → 운전 가이드, 공조 자율 운전 14% 절감(회사 발표). — [뉴스룸](https://news.skhynix.co.kr/netzero_aidt/)

## 2. 데이터와 정할 것
- **데이터**: 냉동기·공조 운전 변수, 외기 온습도, 전력 사용량
- **정할 것**: 조건별 운전 설정 가이드
- **목표**: 전력 절감률

## 3. 후보 로직 (기준선부터)
1. 배치: 기준선은 '가득 차면 시작', 대안은 '최대 대기 시간이 넘으면 덜 차도 시작'
2. Q-time 걸린 로트 우선 규칙
3. 물류: 최단 경로 vs 혼잡 반영 경로 비교
4. 에너지: 기준선 현재 운전 → 조건별 최적 운전점(회귀 + 안전 범위 제약)
