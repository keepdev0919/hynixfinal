# 주제 찾기 안내

과제 README와 데이터를 읽은 뒤, 아래 표의 "이런 말이 나오면"과 "이런 데이터가 나오면"을 보고 가장 가까운 주제 1~2개를 고른다. 주제 파일에는 현업 상황(출처 포함) → 데이터 모양 → 후보 로직 → 실제 사례만 있다. 일반 개념은 이미 아는 것으로 보고 적지 않았다.
