# 06. 정비 기록·로그 기반 AI 에이전트

상태: 초안.

## 1. 현업 상황과 근거
- 하이닉스 GaiA: 장비 보전 가이드 에이전트(정비 이력·명장 노하우 요약), 로그 분석으로 SSD 불량 분석 시간 20% 이상 단축, 사내 문서 검색(RAG) → 에이전트 → 에이전틱 AI, 사람이 확인하는 방식. — [뉴스룸 2025-10](https://news.skhynix.co.kr/gaia_ep1_biz_ai_agent/), [뉴스룸 2025-08](https://news.skhynix.co.kr/ai-platform-gaia-launching-2025/)

## 2. 데이터와 정할 것
- **데이터**: 정비 이력(자유 문장), 알람 로그, 매뉴얼, 스펙 문서
- **정할 것**: 비슷한 과거 사례 찾기, 표준 조치 추천, 인수인계 요약
- **목표**: 사람마다 다른 조치를 표준화, 분석 시간 단축
- **비고**: 회사가 2025~2026년 가장 밀고 있는 방향(GaiA)

## 3. 후보 로직 (기준선부터)
1. 기준선: 키워드 검색으로 비슷한 과거 기록 찾기
2. 정형화: 자유 문장에서 알람 코드·부품·조치를 뽑아 표로(규칙 + LLM 초안, 사람 확인)
3. 유사 사례 순위 + 근거 문서 함께 표시
4. 요약·인수인계 초안은 LLM, 판정·통계는 고정 코드
